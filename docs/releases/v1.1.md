# MoonlightOS v1.1

MoonlightOS v1.1 adds Firefox ESR to the x86_64 gaming-streaming appliance.
Firefox launches from the same controller-friendly menu as Moonlight and
chiaki-ng, runs natively on Wayland, and keeps its profile after installation.

## Features

- Firefox ESR from the signed Debian 13 repositories
- Full Firefox browsing UI with persistent bookmarks, history, downloads, and settings
- Full-screen black-and-white launcher entry for Firefox
- systemd supervision and return-to-launcher behavior for all three applications
- Debian 13 Trixie appliance image for x86_64 UEFI systems
- Moonlight Qt for Sunshine streaming and chiaki-ng for PlayStation 4/5 streaming
- Keyboard and common gamepad launcher navigation
- Intel graphics, VA-API, PipeWire, wired Ethernet, USB/IP, and optional Tailscale support

## Verification

- Source, syntax, policy, and launcher unit tests
- Local ISO build
- UEFI QEMU boot through the real launcher
- Five-second process smoke checks for Moonlight, chiaki-ng, and Firefox

## Important limitations

- Physical Dell OptiPlex DCC36X3 testing is still required.
- QEMU proves boot and application startup, not Intel VA-API, display audio,
  gamepad behavior inside Firefox, USB/IP hardware, or streaming quality.
- Wi-Fi, Bluetooth setup, HDR, and a general-purpose desktop remain out of scope.
- A live USB is for testing; install to the SSD for supported persistent storage.

See the repository README and `docs/INSTALL.md` for installation and test
instructions.
