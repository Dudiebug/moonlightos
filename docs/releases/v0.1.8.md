# MoonlightOS v0.1.8

MoonlightOS v0.1.8 makes the hybrid ISO's existing Debian installer path an
explicitly tested release feature. The boot menu now names the live and install
paths clearly and adds a no-persistence live option for troubleshooting or
one-off sessions.

CI now performs a complete unattended UEFI installation to a disposable disk,
removes the ISO, boots the installed disk independently, writes configuration,
cold-boots it again, and verifies the configuration and MoonlightOS launcher
readiness marker. This supplements the existing live-boot
smoke test and catches failures in partitioning, filesystem copy, bootloader
installation, or the first installed boot.

Persistence documentation now gives distinct backing directories for
MoonlightOS state, logs, Tailscale, and Bluetooth, and explains live-boot's
directory bootstrap behavior. Rufus and Ventoy instructions are included, but
physical NVMe/SATA installs, second-USB installs, Rufus, Ventoy, and persistent
live media remain explicitly unverified until they are exercised on hardware.
