# MoonlightOS v0.1.9

MoonlightOS v0.1.9 makes the public ISO boot path part of the release gate. The
installer smoke test now starts in OVMF firmware, boots the ISO as removable
media, selects the visible GRUB `Install MoonlightOS` entry, completes an
installation to a blank 32 GiB disk, detaches the ISO, and verifies launcher
readiness and persisted state across two cold disk boots. It no longer passes an
extracted installer kernel or initrd directly to QEMU.

The UEFI and BIOS menus now use a black-and-white, high-contrast palette that
matches the launcher, with an inverted selected item and no Debian splash
artwork. The primary installer entry enables Debian's built-in dark text theme;
advanced, automated, and rescue paths remain present. Boot-menu rewrites retain
their source file modes and remain idempotent.

Browsers are no longer distributed in the ISO. On first setup, the owner may
choose no browser, Firefox ESR, or Chromium; the same choice remains available
in Settings. A selected browser is installed directly from Debian's signed
repositories. The image now carries its third-party notices, exact Debian
binary/source package manifest, pinned Moonlight and chiaki-ng source
snapshots, and their complete license texts.

The release gate publishes a draft containing the ISO, SHA-256 checksum, serial
logs, VM configuration, and firmware/menu screenshots. The draft is made public
only after its downloaded ISO is checksum-verified and completes a fresh install
test. The `0.1.6` and `0.1.8` releases remain unchanged.
