# MoonlightOS v0.1.7

MoonlightOS v0.1.7 keeps the Cage/Wayland appliance model and adds a small
configurable application layer. System and custom command or web applications
now come from validated INI manifests. Terminal, Tailscale setup, diagnostics,
and `nmtui` run in separate full-screen Foot processes so their signals cannot
interrupt the launcher.

Bluetooth discovery now continues until the user leaves Bluetooth settings,
powers the adapter off, or begins an operation; `RESCAN` cleanly restarts it.
The release also adds a first-boot and rerunnable Setup Wizard, an Applications
settings screen, custom Firefox kiosk entries, and a full-screen buffered text
keyboard opened with Guide/Home + X/Square or F12.

Debian's `steam-devices` package supplies broader controller device rules only.
Full Steam, proprietary Steam binaries, i386/multilib support, and global Steam
Input routing are not included. A disabled documentation example shows how the
manifest format could launch Steam after a future supported installation method.

Existing Moonlight, Chiaki-ng, Firefox, support export, display-mode rollback,
USB/IP, and Tailscale service behavior remains in place. Application details in
diagnostics and support exports are sanitized and omit environment values,
arguments, and URLs.

Known limitations: the keyboard is buffered and full-screen rather than an
overlay; custom applications must already exist on disk; live-USB persistence
requirements are unchanged. Physical Bluetooth, controller, audio, display,
TV, HDR, GPU, and OSK usability still require hardware validation.
