# MoonlightOS v0.1.10

MoonlightOS v0.1.10 keeps the focused Cage-based appliance experience while improving device and application control.

- Bluetooth discovery now hides unnamed and MAC-only advertisements while retaining named paired devices.
- Settings can dynamically select any PipeWire output, including onboard, HDMI/DisplayPort, USB, and connected Bluetooth audio.
- Firefox enables the standard EME/Widevine path, uses persistent profile storage, and includes better protected-media diagnostics.
- Keyboard Home and supported controller Guide/Home buttons open managed application controls from fullscreen apps.
- Running Moonlight, Chiaki-ng, Firefox, and configured applications can be resumed or closed without restarting Cage.
- Application order changes immediately with Left/Right in Edit Applications and persists through the existing state file.
- Support exports include safe audio, Bluetooth, Firefox DRM, time, graphics, and managed-process diagnostics.

Disney+ does not currently list Linux in its supported browser configurations. MoonlightOS provides Firefox's legitimate x64 Linux Widevine path but does not bypass service device policy or DRM restrictions.
