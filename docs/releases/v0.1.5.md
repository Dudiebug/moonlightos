# MoonlightOS v0.1.5

MoonlightOS v0.1.5 is a focused reliability release based on physical testing
of v0.1.4.

## Fixes

- Tailscale setup now returns to the same launcher session when closed, reports
  connected/closed/failed status, ignores stale login URLs, and automatically
  returns after authentication completes. The privileged enrollment attempt
  continues independently when the local viewer is closed.
- The unused multi-Escape application-stop feature and its background services
  have been removed. Applications continue to return to the launcher through
  their normal exit and systemd recovery paths.
- Support diagnostics now drop to the launcher user with `setpriv`, collect DNS
  state from NetworkManager and `/etc/resolv.conf`, and include the Wi-Fi and
  USB/IP package versions.
- Support export now creates exactly one archive, validates every member by
  fully streaming it, journals sanitized results, waits briefly for udev, and
  reports success for temporary mounts only after a checked unmount succeeds.
- USB/IP starts with the options supported by Debian's daemon and treats an
  already-unbound cleanup as success. The QEMU smoke test now fails if the
  daemon enters a failed state.
- `wpasupplicant` is explicitly installed so NetworkManager can activate Wi-Fi
  hardware when configured.
- Project builds and releases no longer create checksum sidecars or perform
  digest passes. The release contains only the boot-tested ISO.

## Validation scope

The source regression suite, ISO build, UEFI QEMU boot test, USB/IP service
check, and Moonlight/chiaki-ng/Firefox startup smoke test run before release.
Real tailnet enrollment, removable-media unmount behavior, Wi-Fi association,
audio, graphics acceleration, and target-hardware streaming still require
physical validation and are not claimed by the automated tests.
