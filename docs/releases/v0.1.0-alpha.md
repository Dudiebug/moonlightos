# MoonlightOS v0.1.0-alpha

The first public testing image for the x86_64 MoonlightOS gaming-streaming
appliance. This is an alpha prerelease: its UEFI boot path and launcher startup
passed automated QEMU smoke testing, but the target Dell OptiPlex 7010 Micro
hardware matrix has not yet been physically validated.

## Features

- Debian 13 Trixie appliance image for x86_64 UEFI systems
- Full-screen GTK 4 launcher under Cage/Wayland, with no desktop environment
- Moonlight Qt for Linux Sunshine streaming; Moonlight opens by default
- chiaki-ng for locally reachable PlayStation 4/5 consoles
- Keyboard and common gamepad launcher navigation
- Intel i915, Mesa Vulkan, VA-API, Intel media driver, PipeWire, and ALSA stack
- IPv4-only wired Ethernet with DHCP and recovery after link loss
- Persistent settings, pairings, logs, and application data after installation
- systemd application supervision and return-to-launcher behavior
- Allowlist-only Linux USB/IP for wheels, HOTAS, and specialty controllers
- Fail-closed nftables protection for USB/IP TCP port 3240
- Optional Tailscale host connectivity, diagnostics, and ACL-gated Tailscale SSH
- Debian Installer entry for installation to an internal SSD

## Important limitations

- Physical Dell OptiPlex DCC36X3 testing is still required.
- 4K60 SDR is best effort; HDR is not claimed or supported for acceptance.
- Wi-Fi and Bluetooth setup are outside v0.1.
- Tailscale is installed but disabled and unauthenticated by default.
- USB/IP exports nothing until an explicit device allowlist is configured.
- A live USB is for testing; install to the SSD for supported persistent storage.

Verify the download before writing it to USB:

```bash
sha256sum --check moonlightos-0.1.0-alpha-amd64.iso.sha256
```

See the repository README and `docs/INSTALL.md` for installation and test
instructions.
