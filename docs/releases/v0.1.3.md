# MoonlightOS v0.1.3

MoonlightOS v0.1.3 is a launcher and appliance-reliability update based on
physical testing of the v0.1.2 live image.

## Fixes and improvements

- Adds a minimal black-and-white application startup screen with an animated
  spinner while the systemd application service is becoming ready.
- Adds explicit application startup-failure feedback instead of silently
  returning to the launcher when an application repeatedly fails before its
  readiness marker is reached.
- Restores curses keyboard, timeout, cursor, input-buffer, and session state
  after the Tailscale enrollment terminal UI returns, preventing subsequent app
  launches from inheriting broken launcher state.
- Correctly parses the output of `ip -brief -4 address show up`, ignores the
  loopback address, and displays the first usable non-loopback IPv4 address.
- Support export now detects ordinary writable USB filesystems even when they
  are not already mounted. MoonlightOS temporarily mounts the selected media
  with `nosuid,nodev,noexec`, writes and validates the support archive, syncs
  it, and unmounts media it mounted itself.
- The entire physical USB device containing `/run/live/medium` is excluded from
  generic support-export destinations so the currently booted MoonlightOS stick
  cannot be accidentally selected as arbitrary removable media.

Moonlight Qt remains pinned at 6.1.0 and runs through XWayland with
`QT_QPA_PLATFORM=xcb`. chiaki-ng remains pinned at 1.10.0 and uses native
Wayland. Firefox ESR remains Debian-packaged and native Wayland.

## Validation scope

The source regression suite, ISO build, UEFI QEMU boot test, and automated
Moonlight/chiaki-ng/Firefox startup smoke test run in GitHub Actions before the
release workflow is allowed to publish the ISO. Physical display switching,
controller hardware, Intel acceleration, physical audio, streaming quality,
USB-media behavior still requires qualification on real target hardware.
