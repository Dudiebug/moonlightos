# MoonlightOS v0.1.11

MoonlightOS v0.1.11 adds official Google Chrome while retaining Firefox ESR and the focused Cage-based appliance experience.

- Google Chrome Stable is installed from Google's signed Debian repository; Chromium is not installed.
- Chrome runs natively on Wayland with a persistent profile and appears as a controller-friendly launcher application.
- Newly configured web applications use Google Chrome in kiosk mode.
- Support exports report the installed Chrome package and package source without collecting browser profiles.
- The release ISO passed source tests, live application startup, live persistence, installation, and installed-system cold-boot checks in QEMU.

Google Chrome provides its standard Linux Widevine path, but Disney+ does not currently list ordinary Linux distributions as supported browser platforms. MoonlightOS does not bypass service device policy or DRM restrictions.
